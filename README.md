# E&Y

熊和兔的纪念日。E 是 Evan，Y 是悦。

## 0.1
- 最上面钉着「在一起 X 天」，底下倒数离得最近的下一个日子
- 一条一条的日子，点开放大成一格：照片（图床链接）、这一天、熊写的、兔子的纸条
- 带年份的每年纪念日，点开大字写已经过去多少天

## 0.2
- 三个页签：日子、抽屉、美化
- 抽屉：月历，每格左边兔子的心情、右边熊的心情；经期小红点；纪念日小圆点；点开某一天贴心情、点红点、贴米黄小纸条
- 美化：大框贴纸和心情图标都存链接，换图不用重新导入
- 大框：粉边便签、回形针、右上角贴纸、左下角小熊爪
- 工具：E&Y看纪念日、E&Y熊写一句、E&Y熊贴心情、E&Y看抽屉

## 打包
manifest.json、index.html、icon.png 压成 zip，在应用市场创作页导入。
