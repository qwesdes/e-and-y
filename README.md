# E&Y

熊和兔的纪念日。E 是 Evan，Y 是悦。

## 0.1
- 最上面钉着「在一起 X 天」，从 2026-04-26 零点数，底下倒数离得最近的下一个日子
- 一条一条的日子，点开放大成一格：照片（图床链接）、这一天、熊写的、兔子的纸条
- 可以添、改、删日子；颜色收在 CSS 变量里，以后做美化页
- 工具：E&Y看纪念日、E&Y熊写一句（熊在聊天里往格子底下写话）

## 打包
manifest.json、index.html、icon.png 压成 zip，在应用市场创作页导入。icon.png 暂时借书架的。
